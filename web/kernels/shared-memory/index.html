Ranking: occupancy on the chosen GPU → fewer shared loads per pixel → less halo loading → less shared memory. Model: bank = word index mod 32; same-word reads broadcast; 8-byte lane loads are served in 2 half-warp phases, 16-byte loads in 4 quarter-warp phases (Programming Guide behaviour; confirm in Nsight Compute with l1tex__data_bank_conflicts_pipe_lsu_mem_shared_op_ld.sum). Rankings are rule-based, not a timing model.
